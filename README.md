# ND dyed-diesel emergency order (EO 2026-08): policy brief

A short brief on North Dakota's Sept. 29, 2026 order letting licensed ag vehicles use red-dyed diesel on the road through Nov. 30.

- `brief.md` / `brief.pdf`: the brief (about 1,800 words, 2 exhibits)
- `by_the_numbers.md` / `by_the_numbers.pdf`: a short "Ag by the Numbers" piece for general readers (text and charts generated by `analysis/btn_text.py` and `analysis/btn_figures.py`, with every calculation shown)
- `diesel_relief_article.docx`: the article (author's template and Oct. 2 edits; corn and soybeans only), with Figure 1 and Tables 1–2. The generator reproduces the author-edited text; check before regenerating if the Word file has been edited again. Build: `python analysis/simple_estimate.py && python analysis/article_data.py && node analysis/make_article_docx.js`
- `simple_estimate.docx`: the headline five-parameter estimate (corn, soybeans, wheat), used in the brief, appendix and Ag by the Numbers piece. Build: `python analysis/simple_estimate.py && node analysis/make_simple_docx.js`
- `methods_inputs_and_calculations.docx`: supplement on the fuller cross-check model. A Word document with a sourced table of every input and a step-by-step calculation walk-through (build: `python analysis/methods_doc_data.py && node analysis/make_methods_docx.js`, needs `npm install docx`)
- `appendix.md`: full calculations, parameter table, bottom-up/top-down reconciliation, sensitivity
- `memo_critical_facts.md`: the pre-modeling fact check (federal tax, EPA, EO scope, other states)
- `params.yaml`: sourced inputs (with report, table and local file), plus a short list of labeled bounds and one scenario
- `analysis/derive.py`: computes every model parameter from those inputs; `analysis/vius.py` tabulates the VIUS microdata
- `analysis/`: plain Python (pandas, matplotlib, pyyaml)
- `data/raw/`: every downloaded file; `data/SOURCES.md` lists URLs, access dates and manual steps
- `outputs/`: `results.json`, CSV tables, `fig_prices.png`

## Reproduce

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python analysis/run_all.py          # writes outputs/* and regenerates appendix.md
pandoc brief.md -o brief.pdf --pdf-engine=xelatex -V geometry:margin=1in -V mainfont="Helvetica Neue" -V fontsize=10pt
pandoc by_the_numbers.md -o by_the_numbers.pdf --pdf-engine=xelatex -V geometry:margin=0.9in -V mainfont="Helvetica Neue" -V fontsize=10pt -V colorlinks=true -V urlcolor=blue
```

The analysis reads only local files in `data/raw/`, so it runs offline. To refresh the EIA prices, re-download the two `.xls` files listed in `data/SOURCES.md`. `analysis/fetch_text.py` is the helper used to capture web pages; the analysis does not need it.

## Headline results (five-parameter estimate; corn, soybeans, wheat; trucks only)

| | Only farm-tank trucks switch (53%) | Every eligible truck switches |
|---|---:|---:|
| Truck diesel gallons switched | 2.5 M | 4.8 M |
| Farmer savings = state revenue forgone | $0.5 M | $0.9 M |
| Share of fall corn/soybean harvest-and-haul fuel shock offset | 0.4% | 0.7% |

Haul distance (21.7–41.7 mi) moves the all-switch figure from $0.7 M to $1.4 M. The fuller model (`analysis/run_all.py`, `methods_inputs_and_calculations.docx`) is kept as a cross-check: $0.6 M. Federal revenue forgone is $0.

## How assumptions are handled

- Every model parameter is computed in `analysis/derive.py` from a sourced input in `params.yaml`. `outputs/derived_params.csv` and appendix §A2 record each calculation.
- Where no source exists, the quantity is stated in `params.yaml` under `bounds` as a **BOUND** (logical limits, midpoint central). Appendix §A9 shows how much each one moves the result.
- **Scope choices (Oct. 2):** farm pickups are excluded because the 2021 VIUS sample of diesel farm pickups is too thin (effective n ≈ 12), which biases totals down. Every operator with dyed fuel on hand is assumed to use it on-road despite federal penalty exposure (risk acceptance = 100%), which biases totals up.

## Open questions and unverified items

1. **IRS relief.** None found for ND as of 9/30/2026, and ND's release doesn't say it has asked. Precedent says relief waives only the penalty; the 24.4¢ is still owed. The White House is reportedly weighing broader federal dyed-diesel relief (Reuters, 9/28). Re-check before publishing.
2. **Is the 23¢ legally waived?** EO §8 says no tax is waived unless done so expressly, and §57-43.2-41(1) otherwise assesses the 23¢ on the full tank. The brief assumes the practical effect is the advertised 19¢. This needs written Tax Commissioner confirmation.
3. **Signing date.** The release and press say Sept. 29. The handwritten day on the signed PDF is hard to read and looks like "27th."
4. **AAA prices** (ND $6.14 on 9/30, $6.25 record on 9/21; U.S. $6.53 record on 9/22) are taken from InForum and were not checked against AAA directly.
5. **Dyed vs. clear rack spread.** No free source was found. The analysis uses the statutory 19¢, which is what the order changes.
6. **Data vintages and proxies:**
   - UGPTI DP-284 describes the 2013 crop.
   - VIUS 2021 is national for agriculture; the ND-only sample is too small.
   - Off-farm shares come from 2024–25 grain stocks and include a little old crop.
   - Sugarbeet harvest fuel uses a corn proxy.
   - 2025 production stands in for sunflower, potatoes and canola.
   - All proxies are listed in appendix §A9.
7. **Elasticities.** Dahl (2012), U.S. diesel ≈ −0.07, comes from a secondary citation; the table itself was not seen. The Winebrake et al. (2015) values come from abstracts. The brief claims only "near zero in the short run."
8. **Other states.** SD, MN and MT were checked through governors' releases and news as of 9/30. AR and IN are from news reports. SD's governor said further steps are under review.
9. **Crop data vintage.** Uses the Sept. 1 NASS forecasts; the Oct. 9 report will move tonnage slightly.
10. **Take-up evidence.** No data on actual use of any past emergency dyed-diesel allowance were found. Risk acceptance is set to 100% by assumption. The 'fueled at own facility' share (53%, VIUS Class 6–8 farm trucks) is a proxy for dyed fuel on hand; ND-only trucks show 64% and Northern Plains 47%.
